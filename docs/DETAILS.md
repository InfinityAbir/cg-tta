# CG-TTA release: technical details

This is the long reference for the Camelyon17 part of the repository (data layout, GPU jobs, caveats). The top-level `README.md` is the short guide.

Code and per-seed predictions for *Help Versus Harm: Auditing Test-Time Adaptation of Pathology Vision
Transformers on Camelyon17 with a Label-Free Consensus Gate* (CG-TTA).

Every number, table and figure in the paper can be regenerated from this bundle
on a CPU, without the WSI dataset and without a GPU. The GPU jobs that produced
the predictions are included as resumable Colab scripts. `colab_pro/` holds the
revision jobs (Center-1 threshold locking, Phikon with EATA-LN, the fixed
held-out budget design, a fifth Center-0 seed, GPU timing) and their post-processing;
`revision_colab/` holds the outputs of those jobs (per-patch predictions where
they were saved, per-run summaries, logs) so `postprocess_colab.py` rebuilds the
revision tables from this bundle alone. `tests/test_shot_im.py` checks the
SHOT-IM sign; `code/twoway_bootstrap.py` and `code/check_paper_numbers.py` add
the slide x seed interval and a prose-vs-CSV check.

```

                    target predictions (npz)
  revision_colab/   outputs of the revision Colab jobs: center0/seed5, center1/ (locked

  tables/           CSVs + LaTeX fragments - paper tables, including the five-seed Center-0,
```

## 1. Verify the release

**One command:** `python rebuild_all.py` runs the self-test, regenerates every table, CSV, JSON and LaTeX fragment from the stored predictions and from `revision_colab/`, and compares each file byte for byte with the archived copy. It prints `REBUILD PASS` and exits 0 only if every check passes. The step-by-step commands below do the same thing one script at a time.

```bash
pip install -r requirements.txt
python code/cg_tta.py --self-test        # gate, metrics, Table II, ablation
```

Expected tail:

```
Table II: 8 methods x 5 seeds rebuilt, max deviation 4.547e-13
Gate ablation: 6 gates x 5 seeds rebuilt, max deviation 2.220e-16
Center-0: 8 methods rebuilt, max deviation 0.000e+00
Proposition 1 checked on 18 (seed, adapter) pairs: PASS
SELF-TEST PASS
```

Then regenerate the paper's tables into a scratch directory and diff:

```bash
CG_TTA_OUT=/tmp/regen python code/reproduce_tables.py            # 13 core CSVs
CG_TTA_OUT=/tmp/regen python code/make_postsubmission_tables.py  # 6 extension CSVs
CG_TTA_OUT=/tmp/regen python code/make_tables.py                 # 5 tab_*.tex
python code/make_figures.py                                        # 3 PDF + 3 PNG
```

The first script regenerates the primary Center-2 and budget CSVs. The second
regenerates the five-seed Center-0, full-EATA and Phikon CSVs. `make_tables.py`
uses `core_center0_multiseed_summary.csv` for `tab_center0.tex`; the older
single-seed `core_table_center0.csv` is retained as provenance and is not used by
the manuscript table.

All 22 regenerated CSV and JSON files (including the cross-center harm indicator and paired-difference tables) are byte-identical to `tables/`. The PNGs are
byte-identical to `figures/`; the PDFs differ only in matplotlib's embedded
creation timestamp, not in content. `make_figures.py` needs Times New Roman,
the font used in the paper.

## 2. How CG-TTA is reconstructed

The bundle stores the five raw streams per seed - `no`, `tent`, `flip`, `eata`,
`shot` - and derives the CG-TTA rows rather than storing them, so the gate can
be audited. With `y0`, `y1`, `yf` the argmax labels of the frozen, adapted and
four-view critics:

```python
accept = (y0 != y1) & (yf == y1)
y_safe = np.where(accept, y1, y0)
```

Probabilities are carried the same way: the adapter's probability vector where
the gate accepts, the frozen vector otherwise. `code/cg_tta.py` implements
this in numpy (`consensus_gate`) and in torch (`consensus_gate_torch`) and the
self-test checks that both agree.

Two conventions matter and are enforced in the code:

* **Pre-update scoring.** Batch *k* is scored with `theta_{k-1}`, before its own
  update. The final parameters `theta_K` never score the evaluated stream. This
  is `CG-TTA.step()` and it is what every main-paper number uses.
* **Critic parameters.** The four-view critic is the *frozen* model
  `f_{theta_0}`, never the adapted one.

The one documented exception is the held-out budget evaluation: the fixed 10%
set is disjoint from the adaptation stream and is scored once with `theta_K`.

## 3. What each directory contains

**predictions/center2/seed{1..5}/{no,tent,flip,eata,shot}.npz** - 85,054
patches of Center 2 for one source seed each. Keys:

| key | dtype | meaning |
|---|---|---|
| `probabilities` | float32 (N,2) | softmax output of that method |
| `predictions` | uint8 (N) | argmax label |
| `labels` | uint8 (N) | ground-truth tumor label |
| `patch_ids` | int32 (N) | row index into the WILDS `metadata.csv` |
| `slides` | int16 (N) | slide ID, 10 slides |

**predictions/center0/seed{1..5}/** - the Center-0 rotation, 59,436 patches,
same keys. All five seeds are used in the manuscript's Center-0 table. Here
`patch_ids` are positions inside the Center-0 subset, in metadata order, not
global row indices. Seed 5 comes from the revision Colab run; its original files
are also in `revision_colab/center0/seed5/`.

**predictions/eata_full/seed{1..3}/{no,eata}.npz** - full-parameter EATA on
Center 2, 85,054 patches, 5e-5 post-hoc calibration. The frozen four-view
critic is not duplicated: the gate reads `predictions/center2/seed*/flip.npz`.
**predictions/eata_full/seed1_lr2.5e-4/** is the preserved pre-specified
2.5e-4 collapse.

**tables/** - `core_table2_main.csv` (Table II), `core_table_gate_ablation.csv`,
`core_primary_endpoints.csv`, `core_coprimary_holm.csv`,
`core_secondary_endpoints.csv`, `core_seed_sign_consistency.csv`,
`core_per_slide_delta.csv`, `core_method_slide_metrics.csv`,
`core_method_seed_metrics.csv`, `core_residual_harm_decile.csv`,
`core_risk_coverage.csv`, `core_budget_common_support.csv`, plus the `tab_*.tex`
fragments used by the manuscript. The five-seed Center-0 table is generated
from `core_center0_multiseed_summary.csv`, with the underlying
`core_center0_multiseed_{seed_metrics,slide_metrics}.csv`. The full-EATA and
Phikon results are `core_eata_full_{summary,seed_metrics}.csv` and
`core_phikon_probe.csv`. `core_table_center0.csv` is the single-seed pilot,
retained for provenance only.

**data/** - raw rows behind the budget and risk-coverage tables. In
`budget_common_support_summary.csv`, `dacc_mean` is budget minus 100% accuracy,
so negative means the smaller budget is worse.

**logs/** - `seeds.csv` maps each run to its checkpoint and SHA-256;
`checkpoint_sha256.json` records that those hashes were computed post hoc, after
the runs, and were not stored at evaluation time; `environment.txt` records the
environment used for regeneration. `postsubmission_runs.md`,
`postsubmission_runs.json`, `phikon_probe.json` and `eata_full_lr.md` record the
post-submission runs, including the 2.5e-4 collapse and the 5e-5 calibration.

## 4. GPU jobs

`colab/colab_cg_tta_gpu.py` is one self-contained file for the GPU jobs behind
the original Center-0 (seeds 2-4), Phikon-probe and full-EATA results. The
revision jobs (Center-1 locks, Phikon online TTA, held-out budget, Center-0 seed 5,
GPU timing) are in `colab_pro/cgtta_colab.py`; see `colab_pro/README_COLAB.md`.
The predictions are already included, so the scripts are only needed to rerun
adaptation from images.

```bash
python colab_cg_tta_gpu.py preflight           # GPU, disk, data, checkpoints
python colab_cg_tta_gpu.py smoke --local-dir /content/work   # ~1 min, any device
python colab_cg_tta_gpu.py center0      --seeds 2 3 4
python colab_cg_tta_gpu.py budget_heldout --seeds 1 2 3 4 5
python colab_cg_tta_gpu.py phikon       --seeds 1             # frozen probe
python colab_cg_tta_gpu.py eata_full    --probe --lr-full 5e-5
python colab_cg_tta_gpu.py eata_full    --seeds 1 2 3 --lr-full 5e-5
python colab_cg_tta_gpu.py verify              # re-audit everything on disk
```

The Center-0 seeds 2-4, Phikon seed-1 probe and full-EATA seeds 1-3 were run with
this file. The revision jobs were run with `colab_pro/cgtta_colab.py`:
`lock_thresholds`, `phikon` (five heads, online TTA with EATA-LN), `budget_heldout`
(five source seeds), `budget_slideout` (whole-slide held-out budget, source seeds 2, 3, 5)
and `center0 --seeds 5`. Only `eata_full --seeds 4 5` remains
unrun.

Only this one file needs to be on Drive. Put it at

(`Camelyon17-WILDS/...`, `Camelyon17_WILDS_Local_Archive/02_Source_Models/`) is
found relative to `MyDrive/Next Research` automatically.

```python
from google.colab import drive
drive.mount('/content/drive')
!mkdir -p /content/cg_tta
!cp "/content/drive/MyDrive/Next Research/cg_tta/colab_cg_tta_gpu.py" /content/cg_tta/
%cd /content/cg_tta
```

```bash
!python colab_cg_tta_gpu.py preflight     # must end with "preflight PASS"
!python colab_cg_tta_gpu.py smoke --local-dir /content/work   # "SMOKE PASS"
```

Before the first real Center-0 run, validate the whole job path on 2.5k/0.6k/0.6k
patches, one epoch, all five streams:

```bash
!python colab_cg_tta_gpu.py center0 --seeds 2 --canary --max-hours 0.5
```

It writes to `15_SafeTTA_TMI_canary/`, takes about 10 minutes, and must end with
`verify[]: ... PASS`. It exercises staging, training, checkpoint reload, Fisher,
the battery and `finalize`; delete the canary folder afterwards.

Then one job per session, in this order of value:

```bash
!python colab_cg_tta_gpu.py center0 --max-hours 9          # seeds 2 3 4 5
!python colab_cg_tta_gpu.py phikon --seeds 1 2 3 4 5 --with-tta --max-hours 9   # needs HF_TOKEN
!python colab_cg_tta_gpu.py eata_full --probe --lr-full 5e-5   # 200-batch diagnostic, run first
!python colab_cg_tta_gpu.py eata_full --lr-full 5e-5 --max-hours 9
!python colab_cg_tta_gpu.py budget_heldout --max-hours 9
```

`phikon` always fits the frozen linear probe; `--with-tta` additionally runs the
five-method battery on the Phikon encoder, which is what tests whether the gate
behaves differently on a pathology-pretrained backbone. `eata_full --probe`
prints selection rate, accuracy and loss over 200 batches before any long run:
if accuracy collapses or loss is not finite, stop. LayerNorm adapters use SGD
1e-3; full-parameter EATA defaults to the published EATA step of 2.5e-4
(`--lr-full`), because 1e-3 over 85M parameters is not a fair baseline.

**Full-parameter EATA: 2.5e-4 collapse and 5e-5 calibration.** On the full
85k-patch Center-2 stream, the published 2.5e-4 step is unstable: seed 1 fell to
0.7429 accuracy with 19,543 harms and ECE 0.2463, against a 0.9490 frozen
baseline. That run is preserved as the pre-specified negative result. The
multi-seed baseline uses `--lr-full 5e-5`, a post-hoc stability calibration
chosen after the collapse (a factor of five below the pre-specified step). Seeds
1-3 reach 0.9543, 0.9517 and 0.9319. The 200-batch probe at 2.5e-4 looked
healthy (0.9655 accuracy), so the probe is a memory/time check, not a stability
proof: the collapse only appears over the full stream. Both configurations are
kept, and the calibration is reported as post hoc rather than as the
pre-specified protocol. Details: `logs/eata_full_lr.md`.

If the runtime recycles, mount Drive again, copy the script again, and re-run the
same command: it resumes from the last saved batch. Results land in
`MyDrive/Next Research/03_Experiments/15_SafeTTA_TMI/` together with
`environment.json` and `pip-freeze.txt`.

Staging copies the dataset archive to local scratch once per session (one
sequential read of a single file) and extracts the needed patches locally. That
is much faster than opening hundreds of thousands of small files on Drive, and
it also recovers files the extracted tree is missing. Budget 10-25 min for the
first job in a session; later jobs reuse the archive copy. Do not kill the
session during "stage[...]" - it resumes where it stopped if you re-run.

**Resume.** State is saved every `SAVE_EVERY` batches (`state.pkl`: batch index,
optimizer state, RNG state, adapting parameters, EATA selection counters) and
mirrored next to it on Drive. Re-running the same command resumes mid-stream.
`--max-hours N` stops cleanly between batches and exits 0. Completed units are
skipped via `status.json`. Nothing is recomputed.

**Verified on CPU.** `smoke` runs all four modes (`no_tta`, `tent`, `eata`,
`shot`) on a toy model, forces a stop at batch 4 of 12, resumes, and compares
against an uninterrupted run: probabilities, labels, IDs and slides are
bit-identical, and every adapter is asserted to have moved a parameter so the
comparison is not vacuous. It then writes summaries and runs the same
`verify_job` audit used on GPU.

**Execution status.** The Center-0 seeds 2-5, the Center-1 threshold locks, the
Phikon five-head online battery (frozen, TENT, EATA-LN, Flip-TTA, CG-TENT), the
held-out budget experiment (five source seeds, TENT only) and full-parameter EATA
seeds 1-3 at 5e-5 are complete and included in the manuscript. The 2.5e-4 collapse
is preserved as the pre-specified negative result. Full-EATA seeds 4-5 and Phikon
on Center-0 were not run and are not claimed. Held-out budget seeds 1 and 4 saved
summary metrics only, without per-patch predictions. Details:
`logs/postsubmission_runs.md` and `colab_pro/README_COLAB.md`.

### Center-0, full-EATA and Phikon results

Center-0, five source seeds, patch accuracy; delta is vs the same-seed frozen
model. Harm is the per-seed mean number of patches where the frozen prediction
was correct and the method's was wrong.

| method | accuracy | delta (pp) | harm/seed |
|---|---|---|---|
| Frozen | 0.9587 | - | - |
| TENT | 0.9618 | +0.31 | 68 |
| Flip-TTA | 0.9649 | +0.62 | 303 |
| EATA-LN | 0.9611 | +0.24 | 44 |
| SHOT-IM | 0.9486 | -1.01 | 802 |
| CG-TENT | 0.9614 | +0.27 | 8 |
| CG-EATA | 0.9609 | +0.22 | 5 |
| CG-SHOT | 0.9596 | +0.09 | 84 |

TENT, EATA-LN and Flip-TTA are positive on 5/5 seeds; SHOT-IM is positive on
1/5, so "seed-unstable" is the supported description. At slide level,
CG-TENT and CG-EATA are within 0.01 pp of their adapters (0.95669 vs
0.95662 and 0.95630 vs 0.95628) and cut harm by about 88%. CG-SHOT is
+0.63 pp over SHOT at slide level, but sits below frozen on seeds 2 and 5
(by 0.17 and 0.04 pp).

Full-parameter EATA, Center-2, 5e-5 (post hoc calibration):

| seed | frozen | EATA-full | CG-EATA-full | EATA harm | CG harm |
|---|---|---|---|---|---|
| 1 | 0.9490 | 0.9543 | 0.9547 | 975 | 58 |
| 2 | 0.9182 | 0.9517 | 0.9290 | 651 | 76 |
| 3 | 0.9099 | 0.9319 | 0.9191 | 2,172 | 173 |
| mean | 0.9257 | 0.9460 | 0.9343 | 1,266 | 102 |

The gate cuts mean harm by 92% (1,266 to 102) but costs 1.17 pp relative to the
adapter (0.9460 to 0.9343); it still gains +0.86 pp over frozen. This is a
**safety-accuracy trade-off**, not accuracy preservation. The LayerNorm-only
adapters change fewer predictions and their correct flips are more often
confirmed by the critic, which is why the gate preserves their accuracy; the
full-parameter adapter produces many correct flips the critic does not confirm.
The per-seed table shows the same boundary: the gate is +0.04 pp on seed 1 and
-2.27/-1.28 pp on seeds 2/3 relative to the adapter.

Phikon frozen linear probe, seed 1: target accuracy 0.9432, AUROC 0.9915, ECE
0.0247, validation balanced accuracy 0.9893. The supervised ViT-B seed-1
baseline is 0.9490, so the difference is -0.58 pp.

Phikon online TTA, Center-2, five independently fitted linear heads (frozen
encoder, LayerNorm adaptation, same streaming protocol; table
`revision_colab/tables/phikon_eata_summary.csv`): TENT gains +2.74 pp with 227
harms per seed and EATA-LN +2.59 pp with 204; CG-TENT keeps +0.63 pp with 12
harms, so on this encoder the gate removes most harm at the price of most of the
gain. Phikon on Center-0 was not run.

**Cost on a T4, order of magnitude.** Center-0: ~4-8 h per seed, source
fine-tuning plus the five-method battery (seed 5: 7 h 58 min wall, early stop at
epoch 7). Budget held-out: ~1 h 50 min per source seed. Phikon: ~4 h 48 min for
five heads including the online battery. Center-1 threshold locking: ~4.5 h.
Full-parameter EATA: ~2 h per seed. Use `--probe` first for the two memory-heavy
jobs. On an A100 80GB these figures drop by roughly a factor of three.

**Learning rates.** TENT, EATA-LN and SHOT-IM adapt LayerNorm only and use SGD
1e-3. Full-parameter EATA defaults to SGD 2.5e-4, the value in the EATA paper,
and a Fisher estimated once on 1024 target patches before the stream. That step
diverged over the full stream; the calibrated runs pass `--lr-full 5e-5`. See
the calibration note above and `logs/eata_full_lr.md`. The 200-batch probe did
not catch the divergence, so treat it as a memory/time check rather than a
stability proof.

### Manuscript tables are generated, not typed

Every table in the paper and its supplement is an `\input` file built by scripts: `make_tables.py` (main-paper tables), `make_supplement_tables.py` (14 supplement tables that used to be typed by hand, written as `tables/supp_*.tex`), `make_cost_table.py` (class-conditional cost table and per-seed counts) and `postprocess_colab.py` (revision tables). Their inputs are the stored predictions and the CSV/JSON files in `tables/` and `revision_colab/`. `partition_counts.py` needs the dataset's `metadata.csv` and was run once; its output `tables/partition_counts.csv` is shipped. `rebuild_all.py` regenerates all of them and byte-compares each with the archived copy.

### Revision outputs and how to rebuild them

```bash
python colab_pro/postprocess_colab.py --root revision_colab --center2 predictions/center2
CG_TTA_OUT=/tmp/regen python code/harm_indicator_cross_center.py
CG_TTA_OUT=/tmp/regen python code/make_cross_center_figure.py
```

The first command rebuilds `deployment_locked_*` (Center-1 locked thresholds applied
to Center-2), `phikon_eata_*`, `budget_heldout_*`, `center0_*` and `timing_gpu.*` into
`revision_colab/tables/`. The held-out budget set is identified by `eval_sha256`
2a86a8fe1c2e (8,491 patches, selected by md5(patch id) mod 10 = 0).
`harm_indicator_cross_center.py` reproduces the Center-2 values of the earlier
harm-indicator table to within 1.2e-4 and adds all five Center-0 seeds.

## 5. Data

The Camelyon17 WILDS patches are not redistributed here. `patch_ids` refer to
rows of the dataset's `metadata.csv` and are meaningless without it. The
predictions are sufficient to recompute every table; the images are needed only
to rerun adaptation or to train a new source model.

## 6. Scope and caveats

* The Center-0 rotation uses five source seeds. The source checkpoints for seeds
  2-5 were not archived in the artifact zip, so `logs/seeds.csv` marks them "not
  archived locally"; the predictions are the authoritative artifact.
* The held-out budget experiment splits patches, not slides: the held-out 10% shares
  its ten slides with the adaptation pool. It scores the final parameters rather than
  the online stream, covers TENT only (no gate), and has per-patch predictions for
  source seeds 2, 3 and 5 only. The older Seed-1 fixed-support analysis is post hoc.
* EATA-LN and SHOT-IM are controlled variants under the same LayerNorm-only
  budget as TENT, not reproductions of the published methods.
* Full-parameter EATA uses `--lr-full 5e-5`, chosen after the pre-specified
  2.5e-4 step diverged on target accuracy. That is a post-hoc calibration
  informed by target labels; the 2.5e-4 run is kept as a negative result.
* The CG-TTA gate is not accuracy-neutral on full-parameter EATA: it cuts
  harm by 92% but costs 1.17 pp relative to the adapter. Do not cite the
  full-EATA row as evidence that the gate preserves accuracy. The accuracy
  preservation result is for the LayerNorm-only adapters.
* The Phikon online battery covers Center-2 only, with frozen, TENT, EATA-LN,
  Flip-TTA and CG-TENT; there is no Phikon run on Center-0, and the gate keeps only
  part of TENT's gain on this encoder. The `--rotation center0` option of the `phikon` job exists but was never run and is untested.
* The gate-ablation `random_matched` row uses `numpy.random.default_rng(100 +
  seed)`; the self-test reproduces it exactly, including the help/harm counts.
* Checkpoint hashes were computed after the experiments; see the note in
  `logs/checkpoint_sha256.json`.
* The Center-0, full-EATA, Phikon and held-out budget extensions are reported with
  their caveats in the manuscript; full-EATA seeds 4-5 and Phikon on Center-0 remain
  future work.
